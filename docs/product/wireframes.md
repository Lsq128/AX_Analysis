```

│                                                             │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │ ⚡ 快速诊股  │  │ 📈 技术趋势  │  │ 📰 资讯舆情  │         │
│  │  ~5 分钟    │  │  ~5 分钟    │  │  ~8 分钟    │         │

│  │  [选中边框]  │  │             │  │             │         │

│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │ 📊 价值深挖  │  │ ⭐ 全面研判  │  │ 🎯 深度推演  │         │
│  │ 推荐长持研究 │  │  推荐 ·默认  │  │  重大决策   │         │
│  │  2.0 点     │  │  2.5 点     │  │  4.0 点     │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
│                                                             │
│  ℹ 方案说明折叠：包含哪些维度（技术面/舆情/新闻/基本面）         │
```

**交互：**

- 单选卡片；hover 展示「包含分析师」图标行（4 个小 icon 亮/灰）
- 点数 = `方案系数 × AI 引擎系数`（Step 4 才显示最终值，此处显示方案基础系数）
- 体验版用户：「深度推演」卡片显示锁 + 升级提示

### 3.2 五幕节点与引擎映射

| 幕 | UI 节点 | 引擎 agent / state key | 完成判定 |
|----|---------|------------------------|----------|
| 一 | 技术面研判 | `Market Analyst` → `market_report` | report 非空 |
| 一 | 市场情绪 | `Sentiment Analyst` → `sentiment_report` | report 非空 |
| 一 | 资讯与宏观 | `News Analyst` → `news_report` | report 非空 |
| 一 | 基本面体检 | `Fundamentals Analyst` → `fundamentals_report` | report 非空 |
| 二 | 多头研究员 | `Bull Researcher` → `investment_debate_state.bull_history` | 有内容 |
| 二 | 空头研究员 | `Bear Researcher` → `bear_history` | 有内容 |
| 二 | 研究经理 | `Research Manager` → `judge_decision` | 有内容 → **弹出研究结论卡** |
| 三 | 交易员 | `Trader` → `trader_investment_plan` | 有内容 → **交易提案卡** |
| 四 | 激进/中性/保守 | `risk_debate_state.*_history` | 三方均有 |
| 五 | 组合经理 | `Portfolio Manager` → `judge_decision` | 有内容 → **最终评级动画** |

未选中的 Analyst（由分析方案决定）在左侧 **不渲染** 或显示「本方案未包含」。

### 3.3 SSE 事件（Worker 内部，非公开 OpenAPI）

Worker 将 `graph.stream()` chunk 转为前端可消费事件；字段与 CLI `message_buffer` / `ANALYST_REPORT_MAP` 一致即可，**无需先写 OpenAPI 规范**。
